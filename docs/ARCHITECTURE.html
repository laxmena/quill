Pipeline Overview

Quill is a linear pipeline of seven async Python modules. Each stage has a clean public API and can be invoked standalone. processor.py chains them together and runs them on a daily schedule.

Module Reference

bot.py — Telegram Gateway

Receives messages and persists raw content to inbox/

Modes: Webhook (requires public HTTPS URL, uses bot token as path for security) or Polling (fallback when TELEGRAM_WEBHOOK_URL is unset — works on any machine).

Message typeSaved as
TextYYYY-MM-DD_HHMMSS_note.txt
VoiceYYYY-MM-DD_HHMMSS_voice.ogg
PhotoYYYY-MM-DD_HHMMSS_photo.jpg (highest-resolution photo[-1])

transcribe.py — Audio Transcription

OpenAI Whisper · .ogg → .txt

await transcribe(audio_path: Path) -> str
await transcribe_and_save(audio_path: Path) -> Path

Reads the file asynchronously, wraps bytes in io.BytesIO with .name set so the SDK infers the audio format, and calls audio.transcriptions.create(model="whisper-1").

describe.py — Image Captioning

GPT-4o Vision · .jpg/.png → .txt

await describe(image_path: Path) -> str
await describe_and_save(image_path: Path) -> Path

Base64-encodes the image, sends it as a data URI with "detail": "high". Prompt: "Describe this image in one or two sentences as it might appear in a personal biography. Focus on atmosphere, setting, and any human elements."

synthesize.py — Biography Synthesis

Claude Opus · .txt × N → biography HTML

await collect_entries(since, until, inbox_dir) -> list[Entry]
await synthesize(entries, period_start, period_end) -> str
await synthesize_and_save(period_start, period_end, ...) -> tuple[Path, int]

collect_entries globs inbox/*.txt, parses YYYY-MM-DD_HHMMSS_kind.txt stems, filters by date, and returns an ascending-sorted list[Entry].

The Claude system prompt instructs it to write in a Bloomsbury literary voice and emit specific HTML classes (.moment, .divider, blockquote) that slot directly into bloomsbury.html.

Output: biographies/YYYY-MM-DD_content.html (inner HTML only)

render.py — PDF Rendering

Playwright · HTML → A4 PDF + complete HTML page

await render(content_html, period_start, period_end, entry_count, biographies_dir)
    -> tuple[Path, Path]   # (html_path, pdf_path)
await render_from_file(content_path, ...) -> tuple[Path, Path]

_fill_template() performs plain str.replace on {{ token }} placeholders — no Jinja2 dependency. Playwright loads the HTML via file:// so relative ../fonts/ paths resolve, then calls:

page.pdf(format="A4", print_background=True, prefer_css_page_size=True)

prefer_css_page_size=True delegates geometry entirely to @page { size: A4; margin: 28mm 25mm 30mm 30mm } in the stylesheet. The HTML also renders at A4 in a browser via a @media screen block.

deliver.py — Email Delivery

Gmail SMTP · PDF → email

await deliver(pdf_path, period_start, period_end, entry_count) -> None

Uses smtplib.SMTP_SSL on port 465 (immediate TLS, not STARTTLS) wrapped in asyncio.to_thread to keep the event loop unblocked. Validates all three Gmail credentials before attempting a connection in real mode.

processor.py — Orchestrator & Scheduler

Chains all stages · runs daily at PROCESSING_HOUR

async def run_pipeline(period_start, period_end, deliver_email, ...) -> tuple[Path, Path]
async def start_scheduler() -> None   # blocks forever

run_pipeline sequence: process_inbox → synthesize_and_save → render_from_file → deliver → archive_inbox → save_state

Scheduler: Sleeps until the next PROCESSING_HOUR:00. On wake, loads logs/state.json and skips if fewer than BIOGRAPHY_PERIOD_DAYS have elapsed since last_run_date.

Mock System

QUILL_MOCK=true — Set this in .env to replace every external API call with a realistic simulation. No API keys required. The entire pipeline runs end-to-end.

mocks.py provides drop-in clients whose response types mirror the real SDKs field-for-field:

Mock classReplacesKey response fieldsLatency
MockOpenAI openai.AsyncOpenAI .audio.transcriptions, .chat.completions —
_Transcription openai.types.audio.Transcription .text, .language, .duration, .segments 150 ms
_ChatCompletion openai.types.chat.ChatCompletion .choices[0].message.content, .model, .usage 200 ms
MockAnthropic anthropic.AsyncAnthropic .messages —
_AnthropicMessage anthropic.types.Message .content[0].text, .stop_reason, .usage 300 ms

Each module checks the module-level MOCK constant in its _client() factory. Setting QUILL_MOCK=true before any import is enough — no code changes required.

Template System

templates/bloomsbury.html is a self-contained HTML document with two roles:

  • PDF master — Playwright loads it via file:// and renders to A4 via @page { size: A4; margin: 28mm 25mm 30mm 30mm }. Page numbers use CSS counter(page) in @bottom-center.
  • Browser preview — @media screen constrains <body> to 210mm × 297mm with a warm grey background and paper shadow.

Scheduling

processor.start_scheduler() runs an infinite async loop:

while True:
    sleep until next PROCESSING_HOUR:00
    load logs/state.json
    if (today − last_run_date).days < BIOGRAPHY_PERIOD_DAYS:
        skip (biography not yet due)
    else:
        run_pipeline(today − BIOGRAPHY_PERIOD_DAYS, today)
        save state
VariableDefaultEffect
PROCESSING_HOUR2Hour of day (0–23) the scheduler fires
BIOGRAPHY_PERIOD_DAYS14Minimum days between biographies

Pipeline failures are caught and logged without crashing the scheduler — the next run will retry. State is persisted to logs/state.json after every successful pipeline run.

Running at startup on macOS

# Add to crontab (crontab -e):
0 2 * * * /path/to/quill/.venv/bin/python /path/to/quill/cli.py start
